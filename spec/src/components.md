The package uses Design Core controls for shared interaction primitives. Local
CSS owns the Discourse-inspired registry layout and the Slack/Buzz-style
community content because timeline, post stream, room navigation, and
custom-element boundaries are application-specific. Design Core App Shell owns
the workspace geometry, selectors, offstage inertness, focus restoration, and
automatic desktop/mobile presentation. Relay adapters will map Nostr-derived
state into normalized community models through the public controller.

The Inbox, navigation, and workspace wrappers keep explicit docs source so
Storybook does not present test-runtime internals as consumer markup. Loading,
empty, disconnected, permission, and publish-failure states are owned by the
controller/runtime catalog and may be expanded without creating domain-only
fixtures.

After this audit, `RegistryCommunity.stories.svelte` was added as the requested
relay-integration lifecycle story. It renders the production component with a
reusable signed-event scenario and runs through the same memory/Docker backend
selector as the full workspace story.

## Full application action inventory

| Surface                         | Visible result and owner                                                                                                                                                                                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Room toolbar and settings       | Member count opens the reusable member command; Type and Visibility open the shared room editor; ID copies with a toast; Leave and Delete confirm before controller commands. | Profile, search, and extensions | Status publishes through the controller; search shows rooms, loaded/relay messages, and members; unsupported Buzz-only controls are omitted unless the host provides the matching typed extension.                                                                         |
